# Checkliste Objektunterlagen

Priorität: **A** = Pflicht für Erstprüfung · **B** = wichtig, nachfordern · **C** = je nach Objekt

| Kürzel | Dokument | Prio | Worauf achten |
|---|---|---|---|
| EXP | Exposé | A | Soll-Werte (Fläche, Miete, Preis, Faktor) |
| ML | Mieterliste | A | Stichtag, Fläche je Einheit, Nettokaltmiete, NK-Vorauszahlung, Vertragsbeginn/-ende, Kaution, Rückstände, Leerstand |
| GB | Grundbuchauszug | A | Datum (< 3 Monate), Eigentümer, Flurstücke, Abt. II + III |
| FL | Flächenberechnung / Aufmaß | A | Berechnungsgrundlage (WoFlV, DIN 277, gif), Datum |
| MV | Mietverträge | B | Fläche, Miete, Laufzeit, Index/Staffel, Sonderkündigungsrechte, Optionen |
| PL | Grundrisse / Pläne / Schnitte | B | Übereinstimmung mit Flächenberechnung |
| EA | Energieausweis | B | Gültigkeit, Kennwert, Effizienzklasse |
| BL | Baulastenverzeichnis | B | Eintragungen |
| LP | Lageplan / Flurkarte | B | Grundstücksgrenzen, Fläche |
| BG | Baugenehmigungen | B | Nutzung genehmigt wie vermietet? |
| NK | Nebenkostenabrechnungen | B | Umlagefähigkeit, Nachzahlungen |
| OP | Mietkonten / OP-Liste | B | Tatsächlicher Mieteingang, Rückstände |
| VS | Versicherungen | C | Gebäudeversicherung, Schäden |
| WEG | Teilungserklärung, Protokolle, Wirtschaftsplan, Rücklage | C | Nur bei WEG |
| DS | Denkmalschutz / Altlasten | C | Auflagen, Verdacht |
| IH | Instandhaltungshistorie / Wartungsverträge | C | Sanierungsstau, Investitionen |
| FO | Fotos | C | Zustand |
| SO | Sonstiges | – | Alles Übrige |
